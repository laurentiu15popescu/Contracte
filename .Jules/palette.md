## 2024-05-11 - Accessibility on Custom Nav Elements
**Learning:** React custom UI elements like sidebar nav items using `div` with `role="button"` require explicit `onKeyDown` handlers for `Enter` and `Space` keys to maintain full keyboard accessibility. In this case, `tabIndex={0}` was present, but keyboard interactions were missing. Similarly, icon-only buttons (`×` delete button) and search inputs needed `aria-label` attributes for screen readers.
**Action:** Always ensure that custom button elements (`div`/`span` with `role="button"`) implement both `tabIndex={0}` and keyboard handlers (`onKeyDown`) in addition to click handlers. Look out for `input` fields used for searching without attached labels and apply `aria-label` where visual space doesn't allow a standard `<label>`.
